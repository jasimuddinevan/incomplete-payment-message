Displays a full-screen message when payments are incomplete.

== Description ==

This plugin displays a customizable full-screen message on your website when payments are incomplete. The message cannot be closed for a specified amount of time and reappears at regular intervals.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/incomplete-payment-message` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Configure the plugin settings under 'Payment Message' in the WordPress admin

== Frequently Asked Questions ==

= How do I disable the message? =

Go to the plugin settings page and uncheck "Enable Message". You'll need to enter the correct password to make changes.

= What if I forget the password? =

The default password is "123". If you've changed it, you'll need to access the database directly to reset it.
